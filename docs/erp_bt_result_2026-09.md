# 沪深300 股债风险溢价（ERP）回测分析

数据截至 2026-09-30。当前：沪深300 ERP 6.33%，10Y 国债 1.68%。

- IC 为描述性相关系数，月度样本存在收益窗口重叠，有效独立观测数少于 N，结论应保守解读。

- 分段 IC 显示各子区间是否一致为正；某段失效可进一步核查该时段的宏观背景。

**典型案例（2022年4月）：** ERP 5年滚动分位约93.2%，市场估值历史上处于极便宜区间，但随后6个月沪深300价格收益约 −12.6%。同期背景：新冠管控冲击叠加美联储快速加息，分母端（债券收益率）锚定在低位，ERP 主要由估值压缩驱动，而不是盈利改善。2023年5–8月也出现类似失效：经济复苏不及预期，ERP 高位滞留但市场持续调整。这说明 ERP 作为价值信号能识别相对便宜区间，但对短期情绪与基本面修复节奏无法定位，在宏观冲击主导的市场环境中失效概率更高。

## 局限说明
- IC 为描述性相关，月度收益窗口重叠，有效独立观测数少于 N，不能支持统计显著性结论。
- ERP 为盈利收益率口径（1/PE_TTM），非股息率，与部分文献定义不同。
- 数据依赖 AKShare 上游接口，历史序列存在修订风险。
